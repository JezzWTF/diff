## ✨ What Makes This Different?

Most diff tools are utilitarian and boring. This one isn't. With a focus on **visual aesthetics** and **user experience**, our diff checker transforms the mundane task of comparing text into something you might actually enjoy.

- **Stunning Visuals** - Colour-coded changes with thoughtful design that's easy on the eyes
- **Advanced Algorithms** - Multiple diff granularity levels (character, word, line) for precise analysis
- **Three-Way Merge** - Full 3-way comparison with conflict detection and resolution
- **Performance Optimized** - Virtualized scrolling handles massive files with thousands of lines
- **Multiple View Modes** - Split, inline, and compact views for different use cases
- **Intuitive Interface** - No learning curve, just instant productivity
- **Dark/Light Themes** - Because your eyes deserve the best at any time of day
- **Responsive Design** - Works beautifully from desktop down to mobile

## 🚀 Getting Started

### Prerequisites

- Node.js 16+
- pnpm (recommended package manager)

### One-Minute Setup

```bash
# Install pnpm globally if you don't have it
npm install -g pnpm

# Clone it
git clone https://github.com/jezzWTF/diff.git

# Enter the directory
cd diff

# Install dependencies
pnpm install

# Launch it! 🚀
pnpm dev
```

Then open your browser to `http://localhost:5173` and experience the difference!
